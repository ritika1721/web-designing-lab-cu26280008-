# Q5 – PDO Database class and CRUD model

`config/database.php`:
```php
<?php
final class Database {
    private static ?PDO $db = null;
    private function __construct() {}

    public static function connect(): PDO {
        if (self::$db === null) {
            $dsn = 'mysql:host=localhost;dbname=webapp_db;charset=utf8mb4';
            self::$db = new PDO($dsn, 'app_user', 'change_this_password', [
                PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES => false
            ]);
        }
        return self::$db;
    }
}
```

`app/models/Product.php`:
```php
<?php
require_once __DIR__ . '/../../config/database.php';
class Product {
    private PDO $db;
    public function __construct() { $this->db = Database::connect(); }

    public function all(): array {
        return $this->db->query('SELECT * FROM products')->fetchAll();
    }
    public function find(int $id): array|false {
        $s = $this->db->prepare('SELECT * FROM products WHERE id=?');
        $s->execute([$id]); return $s->fetch();
    }
    public function create(string $name, float $price): bool {
        $s = $this->db->prepare('INSERT INTO products(name,price) VALUES(?,?)');
        return $s->execute([$name,$price]);
    }
    public function update(int $id, string $name, float $price): bool {
        $s = $this->db->prepare('UPDATE products SET name=?,price=? WHERE id=?');
        return $s->execute([$name,$price,$id]);
    }
    public function delete(int $id): bool {
        $s = $this->db->prepare('DELETE FROM products WHERE id=?');
        return $s->execute([$id]);
    }
}
```

Create the `products` table in `webapp_db` before running the model.
