# Q15 – Secure file upload

Save uploads outside `public`, for example in `storage/uploads`:
```php
$folder = dirname(__DIR__, 2) . '/storage/uploads/';
if (!is_dir($folder)) mkdir($folder, 0750, true);

if (!isset($_FILES['photo']) || $_FILES['photo']['error'] !== UPLOAD_ERR_OK) {
    exit('Choose a file first');
}
$file = $_FILES['photo'];
if ($file['size'] > 2 * 1024 * 1024) exit('Maximum size is 2 MB');

$mime = (new finfo(FILEINFO_MIME_TYPE))->file($file['tmp_name']);
$types = ['image/jpeg'=>'jpg', 'image/png'=>'png', 'image/webp'=>'webp'];
if (!isset($types[$mime])) exit('Image type not allowed');

$name = bin2hex(random_bytes(16)) . '.' . $types[$mime];
if (!move_uploaded_file($file['tmp_name'], $folder . $name)) {
    exit('Upload failed');
}
echo 'Image uploaded';
```
Use a multipart form and check login permission and CSRF token before upload.
