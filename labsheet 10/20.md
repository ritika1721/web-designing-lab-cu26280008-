# Q20 – MySQL user with limited permissions

Run as a MySQL administrator:
```sql
CREATE USER 'app_user'@'localhost'
IDENTIFIED BY 'replace_with_a_strong_password';

GRANT SELECT, INSERT, UPDATE, DELETE
ON webapp_db.* TO 'app_user'@'localhost';

FLUSH PRIVILEGES;
```
Use `app_user` in the PHP connection instead of `root`. Give only the permissions the application needs. Never upload real passwords to GitHub.
