# Q11 – Validate and sanitize user input

```php
$email = filter_var($_POST['email'] ?? '', FILTER_VALIDATE_EMAIL);
$url = filter_var($_POST['website'] ?? '', FILTER_VALIDATE_URL);
$id = filter_var($_POST['id'] ?? null, FILTER_VALIDATE_INT);
$name = trim((string)($_POST['name'] ?? ''));

if ($email === false || $url === false || $id === false || $name === '') {
    http_response_code(422); exit('Please enter valid details');
}
```
Escape text when displaying it:
```php
echo htmlspecialchars($name, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
```
Use prepared statements for SQL. Validation, output escaping and SQL protection solve different problems.
