# Q13 – Forgot password with expiring reset token

Add columns:
```sql
ALTER TABLE users ADD reset_token_hash VARCHAR(255) NULL,
ADD reset_expires DATETIME NULL;
```

Create a token and save only its hash:
```php
$token = bin2hex(random_bytes(32));
$hash = password_hash($token, PASSWORD_DEFAULT);
$expires = date('Y-m-d H:i:s', time() + 1800);
$s = $db->prepare('UPDATE users SET reset_token_hash=?, reset_expires=? WHERE email=?');
$s->execute([$hash,$expires,$email]);
// Email the raw token in a reset link. Never store it in the database.
```

When the link is opened, check expiry and `password_verify($tokenFromLink, $user['reset_token_hash'])`. After changing the password, clear both reset columns. Use a generic response so the page does not reveal whether an email is registered.
