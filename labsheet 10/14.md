# Q14 – Send email with PHPMailer

Install:
```bash
composer require phpmailer/phpmailer
```

Example helper:
```php
<?php
use PHPMailer\PHPMailer\PHPMailer;
require __DIR__ . '/../vendor/autoload.php';

function sendAppMail(string $to, string $subject, string $body): bool {
    $mail = new PHPMailer(true);
    try {
        $mail->isSMTP();
        $mail->Host = getenv('SMTP_HOST');
        $mail->SMTPAuth = true;
        $mail->Username = getenv('SMTP_USER');
        $mail->Password = getenv('SMTP_PASS');
        $mail->SMTPSecure = PHPMailer::ENCRYPTION_STARTTLS;
        $mail->Port = 587;
        $mail->setFrom(getenv('SMTP_USER'), 'Product App');
        $mail->addAddress($to);
        $mail->Subject = $subject;
        $mail->Body = $body;
        return $mail->send();
    } catch (Throwable $e) {
        error_log($e->getMessage());
        return false;
    }
}
```
Set SMTP values in server environment variables. Do not upload mail passwords to GitHub.
