# Q12 – Login attempt limiter

Add fields:
```sql
ALTER TABLE users ADD failed_attempts INT NOT NULL DEFAULT 0,
ADD locked_until DATETIME NULL;
```

After selecting the account by email:
```php
if ($user && $user['locked_until'] && strtotime($user['locked_until']) > time()) {
    $message = 'Account temporarily locked. Try again later.';
} elseif ($user && password_verify($password, $user['password'])) {
    $s=$db->prepare('UPDATE users SET failed_attempts=0, locked_until=NULL WHERE id=?');
    $s->execute([$user['id']]);
    session_regenerate_id(true);
    $_SESSION['user_id']=$user['id'];
} elseif ($user) {
    $count=(int)$user['failed_attempts']+1;
    if ($count >= 5) {
        $s=$db->prepare('UPDATE users SET failed_attempts=0, locked_until=DATE_ADD(NOW(), INTERVAL 15 MINUTE) WHERE id=?');
        $s->execute([$user['id']]);
    } else {
        $s=$db->prepare('UPDATE users SET failed_attempts=? WHERE id=?');
        $s->execute([$count,$user['id']]);
    }
    $message='Email or password is incorrect.';
}
```
