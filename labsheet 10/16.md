# Q16 – Custom errors and logging

Create simple `404.php` and `500.php` pages with a heading and a link back to the home page. Example:
```php
<?php http_response_code(404); ?>
<h1>404 – Page not found</h1>
<p>The requested page is not available.</p>
<a href="/">Home</a>
```

Production `php.ini` settings:
```ini
display_errors = Off
log_errors = On
error_log = /private/path/storage/logs/php-error.log
```
Use `error_log($e->getMessage())` for technical details. Show visitors a general message only; do not show stack traces or secrets.
