# Q8 – Token authentication and JavaScript fetch

Check a Bearer token before API actions. Store the token hash in a private config or environment variable, not in Git:
```php
$auth = $_SERVER['HTTP_AUTHORIZATION'] ?? '';
$token = preg_replace('/^Bearer\s+/i', '', $auth);
$hash = getenv('PRODUCT_API_TOKEN_HASH') ?: '';
if (!$hash || !password_verify($token, $hash)) {
    http_response_code(401);
    header('Content-Type: application/json');
    echo json_encode(['error'=>'Unauthorised']);
    exit;
}
```

Example browser request for a short-lived test token:
```javascript
fetch('/api/products.php', {
  headers: { Authorization: 'Bearer TEMPORARY_TEST_TOKEN' }
})
.then(response => response.json())
.then(data => console.log(data));
```
Do not put a permanent secret in public JavaScript. A real front end should get short-lived tokens through a login flow.
