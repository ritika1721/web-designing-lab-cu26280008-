# Q6 – Reusable header, footer and views

`app/views/layout/header.php`:
```php
<?php $pageTitle = $pageTitle ?? 'Product App'; ?>
<!doctype html><html lang="en"><head>
<meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1">
<title><?= htmlspecialchars($pageTitle) ?></title></head><body>
<header><h2>Product App</h2>
<nav><a href="/products">Products</a> | <a href="/">Home</a></nav></header><main>
```

`app/views/layout/footer.php`:
```php
</main><footer><p>Product App - <?= date('Y') ?></p></footer>
</body></html>
```

Use in a view with `require`. Pass variables from the controller before loading the view, for example `$products = $model->all();`.
