# Q9 – CSRF token

Start the session before output. Helper functions:
```php
function csrfToken(): string {
    if (empty($_SESSION['csrf_token'])) {
        $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf_token'];
}
function checkCsrf(): void {
    $sent = $_POST['csrf_token'] ?? '';
    $saved = $_SESSION['csrf_token'] ?? '';
    if (!is_string($sent) || !is_string($saved) ||
        $saved === '' || !hash_equals($saved, $sent)) {
        http_response_code(403); exit('Invalid form token');
    }
}
```
Inside each form:
```php
<input type="hidden" name="csrf_token" value="<?= htmlspecialchars(csrfToken()) ?>">
```
Call `checkCsrf()` at the start of every POST handler.
