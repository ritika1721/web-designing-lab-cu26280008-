# Q1 – Git repository and .gitignore

```bash
git init
git status
```

Create `.gitignore`:
```gitignore
/vendor/
/.env
/config/local.php
/storage/uploads/*
/storage/logs/*
*.log
.DS_Store
Thumbs.db
```

Save the first version:
```bash
git add .
git commit -m "Initial project setup"
git status
```
Use small commits with clear messages as you add features.
