# Q3 – MVC folder structure

```text
project/
├── app/
│   ├── controllers/ProductController.php
│   ├── models/Product.php
│   └── views/
│       ├── layout/header.php
│       ├── layout/footer.php
│       └── products/index.php
├── config/database.php
├── public/index.php
├── storage/uploads/
├── storage/logs/
└── .gitignore
```

Model handles database work, View displays the page, and Controller connects the request with data and the view. Set `public` as the web root.
