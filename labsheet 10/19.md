# Q19 – Apache virtual host and hosts file

Example virtual host:
```apache
<VirtualHost *:80>
    ServerName myproject.local
    DocumentRoot "C:/xampp/htdocs/labsheet10/public"
    <Directory "C:/xampp/htdocs/labsheet10/public">
        AllowOverride All
        Require all granted
    </Directory>
    ErrorLog "logs/myproject-error.log"
    CustomLog "logs/myproject-access.log" combined
</VirtualHost>
```

Add to the Windows hosts file as administrator:
```text
127.0.0.1 myproject.local
```
Hosts file path:
```text
C:\Windows\System32\drivers\etc\hosts
```
Restart Apache and visit `http://myproject.local`. Change the folder path to match your computer.
