# Q18 – Local self-signed SSL certificate

For local practice, enable Apache SSL (`mod_ssl`) and configure an SSL virtual host on port 443 with:
```apache
SSLEngine on
SSLCertificateFile "path/to/local-certificate.crt"
SSLCertificateKeyFile "path/to/private-key.key"
```
Generate the certificate using the tool supplied with your local server (XAMPP/WAMP/Linux Apache). Keep the private key outside Git. Browsers will show a trust warning for a self-signed certificate. Use a trusted certificate for a public website.
