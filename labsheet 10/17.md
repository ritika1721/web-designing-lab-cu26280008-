# Q17 – Clean URLs, HTTPS and no directory listing

`public/.htaccess` (Apache `mod_rewrite` must be enabled):
```apache
Options -Indexes
RewriteEngine On

RewriteCond %{HTTPS} !=on
RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [R=301,L]

RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^ index.php [QSA,L]
```
Allow `.htaccess` overrides in the virtual host. Set the web root to `public`.
