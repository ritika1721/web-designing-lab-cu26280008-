# Q2 – Feature branch, merge conflict and GitHub

```bash
git switch -c feature/product-page
# Make a change, then:
git add .
git commit -m "Add product page"

git switch main
git merge feature/product-page
```

To practise a conflict, edit the same lines in the same file on two branches. During merge, open the conflicted file, choose the correct content and remove `<<<<<<<`, `=======`, `>>>>>>>`. Then:

```bash
git add .
git commit -m "Resolve merge conflict"
```

Create an empty GitHub repository, then:
```bash
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git branch -M main
git push -u origin main
```
Replace the sample URL with your repository URL.
